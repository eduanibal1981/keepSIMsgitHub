## 3. Key Operating Principles

1. **Zendit Primary for STC (Zero-Touch Direct Airtime):**
   * STC is routed to **Zendit (`STC_SA_001_USD`)** at $7.10 USD (20 SAR).
   * Delivers 100% automated direct airtime directly into the subscriber balance without requiring manual PIN redemption.
   * **DingConnect (`XCSA`)** serves as Priority 2 direct top-up failover, and **DT One (`3221`)** as Priority 3 PIN backup.

2. **DingConnect Primary for All Other Saudi Operators:**
   * Full coverage across Mobily, Zain, Virgin Mobile, Lebara, Friendi, Salam, and Red Bull.
   * Settles natively in `OMR` (hard pegged at $1\text{ OMR} = 2.6008\text{ USD}$), eliminating floating foreign exchange risk.

3. **Multi-Tier Automated Failover:**
   * When an auto-refill execution runs, KeepSIMs attempts Priority 1 first.
   * If an upstream error occurs, the backend worker automatically cascades to Priority 2 without user intervention.

4. **CST 90-Day Rule Compliance:**
   * KeepSIMs schedules the automated mini-recharge on **Day 80–85** to ensure the 90-day activity timer is reset safely before the SIM reaches suspension.
