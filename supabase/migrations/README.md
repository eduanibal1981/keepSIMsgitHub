From the repository root:

```sh
python3 tools/migration_archive.py verify
python3 tools/migration_archive.py locate <original_filename.sql>
python3 tools/migration_archive.py restore
```

Restore copies original SQL back locally and refuses to overwrite changed files.
It makes no database changes. Original local/remote timestamp differences and
missing original core migrations still require reconciliation before CLI push/reset.
