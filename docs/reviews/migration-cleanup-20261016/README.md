## Evidence and scope

The comparison reads SQL as data and preserves string literals; it does not execute the export. Tables, constraints, policies, permissions, publication state, cron metadata and selected non-sensitive data were checked separately where needed.

Live history has 238 rows. Local migrations often use different timestamps: matching uses exact versions or normalized names. 168 local files map to recorded live history. Another 50 have live structural/routine effects or verified evolved successors without matching history. Twenty-two are obsolete/superseded, including the undeployed unsafe October 4 pricing change. A filename absent from history therefore does not mean its change is missing.

A schema dump cannot prove whether all historical data corrections/seeds ran, nor why an operator omitted history. Unrecorded manual application is an inference when exact bodies are live. The report does not invent application dates or claim byte-identical history based on names alone.
